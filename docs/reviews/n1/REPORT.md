## Gates and next decision

The smallest host extension needed for real N1 is a trusted, company/period/task scoped measurement and remaining-exposure readback, including unsettled work, linked to native run identity and settlement. It must let Council reserve before each launch and settle with authoritative values after execution. Until it exists and is qualified, real activation and dispatch stay closed. The current SDK's single-statement database API supports the plugin-private reservation CAS but cannot atomically commit a separate mission row with it; a crash between them leaves a conservative outstanding reservation.

L1 remains partial because fixture active pinning does not establish real activated operation. The N1 slice of L2 remains partial because the required two attributed contributions and integrated candidate are not demonstrated. PR #14's receipt and hold contract is inherited, while N2 review/verdict, full L03 recovery and N3–N4 are not qualified by N1.
